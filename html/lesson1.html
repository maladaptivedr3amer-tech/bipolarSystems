HTML Notes

What is HTML?

HTML stands for HyperText Markup Language. It is the standard markup language for creating web pages and web applications. HTML describes the structure of a web page semantically and originally included cues for the appearance of the document.

HTML Element Reference

Element Description
<!DOCTYPE html> Tells the browser that it is reading an HTML5 document.
<html></html> Sets the document root. Everything except <!DOCTYPE html> goes inside these tags.
<head></head> Contains metadata and document information that does not appear directly on the page.
<title></title> Sets the page title shown in the browser tab and used by search engines.
<body></body> Contains the visible page content, such as text, images, and links.
<style></style> Used to define CSS styles for the document.
<h1> to <h6> Used to define headings of different levels in the document.
<p></p> Used to define paragraphs of text.
<strong></strong> Used to define strong, important text in the document.
<em></em> Used to define emphasized text in the document.
<a href="url"></a> Used to define hyperlinks. The href attribute sets the destination URL.
<ul></ul> Used to define unordered bullet lists.
<ol></ol> Used to define ordered numbered lists.
<li></li> Used to define list items in ordered and unordered lists.
<span></span> Used to define a small section of inline text.
<img src="url" alt="description"> Used to define images. The src attribute sets the image source, and alt provides alternative text.
<main></main> Used to define the main content of the document.
<header></header> Used to define introductory content for the document or section.
<footer></footer> Used to define concluding content for the document or section.
<section></section> Used to group related content together.
<article></article> Used to define self-contained content.
<div></div> Used to define a general-purpose block container.

Boilerplate

The standard text included in HTML documents is called the boilerplate. A basic example looks like this:

<!DOCTYPE html> <html> <head> <meta charset="UTF-8"> <meta name="viewport" content="width=device-width, initial-scale=1.0"> <title>My Page</title> </head> <body>

CONTENT GOES HERE

</body> </html>

That is the base syntax that should be in all HTML documents.
