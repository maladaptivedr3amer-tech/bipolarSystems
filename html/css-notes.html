CSS Notes

The Box Model

The box model is the way CSS understands every element on a page. Each element is treated like a box made from content, padding, border, and margin.

Content Box

The content box is the area where the actual content is displayed. This can be text, images, links, or other HTML elements.

Padding Box

Padding is the whitespace between the content and the border. It creates breathing room inside the element.

Border Box

The border wraps around the content and padding. It creates a visible edge around the element.

Margin Box

Margin is the outermost space around an element. It creates distance between one element and another.

Content → Padding → Border → Margin

Important CSS Properties

These are the main CSS properties that appear often when building basic layouts.

  • width: controls how wide an element is.
  • max-width: prevents an element from becoming too wide.
  • padding: creates space inside an element.
  • margin: creates space outside an element.
  • border: creates an edge around an element.
  • background-color: changes the background color.
  • font-size: controls the size of text.
  • text-align: controls horizontal text alignment.
  • display: controls how an element behaves in layout.
  • gap: creates space between flex or grid items.

Block and Inline Elements

Block Elements

Block elements start on a new line. They respect width, height, padding, margin, and border.

If no width is set, a block element usually stretches across the full width of its parent container.

<h1>, <p>, <div>, <section>, <article>

Inline Elements

Inline elements do not start on a new line. They sit inside the flow of text.

Inline elements do not handle width and height the same way block elements do. Left and right spacing can push elements away, but vertical sizing can behave differently.

<span>, <em>, <strong>, <a>

Inner and Outer Display

Block and inline are outer display types. They affect how the element itself behaves around other elements.

Flex and grid are inner display types. They affect how the children inside an element are arranged.

Outer Display

display: block;
display: inline;

Inner Display

display: flex;
display: grid;

Wrappers and Containers

A wrapper controls the full website shell. A container controls the readable content width inside each section.

Wrapper Pattern

<body>
<div class="site-wrapper">
<header>...</header>
<main>...</main>
<footer>...</footer>
</div>
</body>

Container Pattern

<section class="section-class">
<div class="container">
Content goes here.
</div>
</section>

Container Rules

  • width controls how wide the container is.
  • max-width stops the container from becoming too wide.
  • margin: 0 auto centers the container horizontally.
  • margin creates space outside the container.
  • padding creates space inside the container.

Font Theory

Typography is the way text is arranged and presented on a page. Good typography makes a website easier to read and easier to understand.

Common Font Properties

  • font-family: chooses the typeface.
  • font-size: controls how large the text is.
  • font-weight: controls how bold the text is.
  • font-style: controls styles like italic.
  • font-variant: controls variant forms like small caps.
  • font: shorthand for multiple font values.

Generic Font Families

  • Serif: Times New Roman, Georgia.
  • Sans-serif: Arial, Verdana, Trebuchet MS.
  • Monospace: Courier New.
  • Cursive: handwriting-style fonts.
  • Fantasy: decorative display fonts.

Font Size Units

Font sizes can use absolute units, relative units, or keyword values. Relative units are usually more useful for responsive web design.

Absolute Units

  • pt: points
  • pc: picas
  • mm: millimeters
  • cm: centimeters
  • in: inches

Relative Units

  • em: based on the current or parent font size.
  • rem: based on the root font size, usually 16px by default.
  • %: based on the parent value.
  • px: pixels, commonly used on screens.

If no font size is specified, browsers commonly use a default size of 16px.

Text and Font Property Reference

  • font: shorthand for font values.
  • font-family: specifies a typeface or generic family.
  • font-size: controls text size.
  • font-style: sets italic or oblique text.
  • font-variant: controls variant text forms.
  • font-weight: controls boldness.
  • letter-spacing: adds space between letters.
  • line-height: controls space between lines of text.
  • text-align: controls horizontal text alignment.
  • text-decoration: adds underline, overline, or strike-through.
  • text-indent: indents the first line of a block.
  • text-transform: changes capitalization.
  • vertical-align: adjusts inline vertical position.
  • visibility: controls whether an element is visible.
  • white-space: controls how whitespace is displayed.
  • word-spacing: adds space between words.

Practice Reminder

CSS becomes easier when each property has a job.

Use padding when the inside of a box feels cramped. Use margin when two boxes are too close together. Use wrappers for the full page shell. Use containers for readable content width.
