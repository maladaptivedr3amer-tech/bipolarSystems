HTML Lesson 1

What is HTML?

HTML stands for HyperText Markup Language. It is the standard markup language for creating web pages and web applications. HTML describes the structure of a web page semantically and originally included cues for the appearance of the document.

Key HTML Elements

Some key elements to remember are:

<!DOCTYPE html>: Tells the browser that it is reading an html 5 document.
<html></html>: Sets the document root. Everything but <!DOCTYPE html> will go in these <html></html> tags.
<head></head>: Contains all the meta and things about the document that wont appear in the browser. Nothing that appears in the document will be in the <head></head> tags.
<title></title>: Sets the title of the document, which appears in the browser tab and the SEO.
<body></body>: Contains the content of the document, such as text, images, and links.
<style></style>: Used to define CSS styles for the document.
<h1> - <h6> Headings: Used to define headings of different levels in the document.
<p></p>: Used to define paragraphs of text.
Strong important text Used to define strong, important text in the document.
<em></em> Emphasis: Used to define emphasized text in the document.
<a href=”url”></a>: Used to define hyperlinks in the document. The href attribute specifies the URL of the page the link goes to.
<ul></ul>: Used to define unordered (bullet) lists in the document.
<ol></ol>: Used to define ordered (numbered) lists in the document.
<li></li>: Used to define list items in both ordered and unordered lists.
<span></span>: Used to define a section of text in the document.
<img src=”url” alt=”description”>: Used to define images in the document. The src attribute specifies the URL of the image, and the alt attribute provides alternative text for the image.
<main></main>: Used to define the main content of the document. It is a block-level element that can be used to group other elements together.
<header></header>: Used to define the header of the document. It is a block-level element that can be used to group introductory content together.
<footer></footer>: Used to define the footer of the document. It is a block-level element that can be used to group concluding content together.
<nav></nav>: Used to define the navigation links of the document. It is a block-level element that can be used to group navigation content together.
<section></section>: Used to define a section of the document. It is a block-level element that can be used to group related content together.
<article></article>: Used to define an article in the document. It is a block-level element that can be used to group self-contained content together.
<div></div>: Used to define a division or section in the document. It is a block-level element that can be used to group related content together.

Boilerplate

The standard text that’s in all html documents is referred to as a boilerplate. The standard boilerplate is as follows:

<DOCTYPE html>

<html>

<head>

<meta charset=”UTF-8”>

<meta name=”viewport” content=”width=device-width, initial-scale=1.0">

<title>My Page</title>

</head>

<body>

–CONTENT GOES HERE–

</body>

</html>

That is the base syntax that should be in all html documents.
