Html Introduction

Hyper text markup language is the standard language for formatting the elements of a web document. It describes the where and what of everything that you see, and some things you don’t, on the page. Html consists of element <Opening> and </Closing> tags that make up the structure of a web page. It labels content such as headings, paragraphs, links and more.

Key Html Tags

Boilerplate

The standard text that’s in all html documents is referred to as a boilerplate. The standard boilerplate is as follows:

<DOCTYPE html>

<html>

<head>

<meta charset=”UTF-8”>

<meta name=”viewport” content=”width=device-width, initial-scale=1.0">

<title>My Page</title>

</head>

<body>

–CONTENT GOES HERE–

</body>

</html>

That is the base syntax that should be in all html documents.
